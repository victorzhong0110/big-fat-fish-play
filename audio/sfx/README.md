# Interface sound effects — CC0

Source: [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), Creative Commons CC0. Retrieved as normalized assets from [NoSpam sound credits](https://github.com/ahhajlou/NoSpam/blob/main/docs/SOUNDS.md).

- `message_sent.wav`: Kenney `drop_004`, from `core/notifications/src/main/res/raw/message_sent.ogg` in `ahhajlou/NoSpam`.
- `message_received.wav`: Kenney `glass_001`, from `core/notifications/src/main/res/raw/message_received.ogg` in the same repository.

Converted OGG to PCM16 WAV with FFmpeg, for browser compatibility. The first clip is shared by menu/action feedback, the second by pickup/level/reward feedback. Per-kind 140ms throttling limits overlap. These are initial shared cues, not a complete bespoke sound library.
